# APL Notebooks

Jupyter Notebooks for the **Automated Predictive Library (APL)** module of the SAP HANA ML Python API.

APL builds predictive models automatically inside SAP HANA — no data science expertise required. It is the same engine powering predictive features in SAP Analytics Cloud (Smart Predict and Predictive Planning).

Sample data is provided with the APL component under the database schema `APL_SAMPLES`.

## Notebooks

- [Classification & Regression](Classification%20%26%20Regression.ipynb)
- [Time Series Forecasting](Time%20Series%20Forecasting.ipynb)
- [Data Drift Detection](Data%20Drift%20Detection.ipynb)

## Prerequisites

- SAP HANA instance with the APL component installed
- [`hana-ml`](https://pypi.org/project/hana-ml/) Python package
- Connection credentials or an `hdbuserstore` key
